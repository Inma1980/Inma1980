## 🙋‍♀️ Sobre mí

Me llamo **Inma Villaverde** y estudio **2º de ASIR** (Administración de Sistemas Informáticos en Red) en el **Liceo La Paz**. 🎓

- 🖧 Me encanta entender **cómo viaja la información**: routers, switches, VLANs y protocolos.
- 🛠️ Disfruto montando **servidores, dominios y máquinas virtuales** (¡y arreglándolos cuando se rompen!).
- 🐍 Empecé a programar desde cero con **Python** y cada script que funciona es una pequeña fiesta 🎉
- 🌱 Ahora mismo aprendiendo: **Docker, Active Directory y automatización**.
- 🎯 Mi objetivo: trabajar como **administradora de sistemas y redes**.
- ⚡ Dato curioso: mi Mac y yo tenemos una relación muy seria con las máquinas virtuales 🍎💜
